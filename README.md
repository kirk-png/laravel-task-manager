## About

A simple Laravel CRUD app for managing personal tasks, built with Routes → Controller → Model → Database → Blade.

## Setup

1. `composer install`
2. Copy `.env.example` to `.env` and set your MySQL database name and login
3. `php artisan key:generate`
4. `php artisan migrate`
5. `php artisan serve`, then open http://127.0.0.1:8000
